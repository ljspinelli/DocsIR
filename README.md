# DocsIR
Ferramenta contábil em Microsoft Excel (.xlsm), desenvolvida no projeto do curso DIO para organizar informações do Imposto de Renda.

A aba Titular centraliza dados pessoais, endereço, contato e informações complementares do contribuinte.
A aba Informes registra instituições bancárias, valores e referências aos arquivos de comprovantes.
Utiliza a função SOMA para consolidar automaticamente os valores bancários informados.
A aba Notas organiza receitas por data, categoria e valor, incluindo holerites, CNPJ e trabalhos freelance.
A aba oculta Tabelas mantém o cadastro bancário e concatena códigos e nomes para alimentar listas suspensas.
Implementa validação de dados para padronizar respostas, categorias e seleção de bancos.
A interface personalizada oferece navegação entre abas por botões com hiperlinks internos.
